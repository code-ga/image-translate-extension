Image Translate Extension is a Manifest V3 browser extension that detects images and canvas elements on web pages, runs OCR with PaddleOCR, and overlays translated text directly on top of the originals in-page with no copy paste. It auto detects images and canvas on page load, SPA navigation, and dynamic DOM changes, translates OCR regions with the free Google Translate API supporting 33 languages, lets you hover any translated box to re translate into another language on demand, runs OCR per item independently so one failure never breaks the batch, and caches translations for speed. Target language is configurable via the popup settings. Stack is WXT, React, PaddleOCR, TypeScript. Install with bun install, run with bun run dev for Chrome or bun run dev:firefox for Firefox, build with bun run build, package with bun run zip, typecheck with bun run compile.
