1. Always prefer using bun.js than using npm or nodejs for typescript,javascript project
2. Always try to understand what the project is about and read PROJECT_DESCRIPTION.md
3. Important: Write this file like you write for an AI agent who doesn't know anything about the project, so they can contribute
4. After each task you will need to update the PROJECT_DESCRIPTION.md file to update the context of the project like
   - [ ] what task each file handle
   - [ ] how flow of the feature work
   - [ ] what function or what file responsible for something
   - [ ] how something work
   - [ ] what need to update in the future, or new idea
   - [ ] the note of feature like warning or notice or etc,...
   - [ ] summarization of walkthrough.md
   In case the project description not found you will create the new one and fill with thing that you know
   NOTE: Some of the project note maybe missing some information so your responsible to update that for fit with current project
5. In some task that is quite big you can create the plan.md with the detail plan and track when each task is done
6. Using type validation after each task for checking when you don't have check and also avoid using type any
7. For react.js (or some frontend project, subproject like that) please try to re-use as many component as possible (include detect the duplicate code and create component for that)
8. After each task you will need to update in changes.md (with header time before adding change)
